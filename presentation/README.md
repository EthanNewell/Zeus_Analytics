# Пакет для сдачи

Файлы пакета собираются из исходников этой папки. Готовые файлы в git не хранятся.

| Что | Исходник | Сборка |
|---|---|---|
| Презентация PDF, 17 слайдов 1600 × 900, по 10 блокам паспорта | `deck.html` | `node build.mjs --png` |
| Презентация PPTX (картинки слайдов) | `png/` | `python3 to_pptx.py` |
| Кадры сервиса для слайдов | статичное демо | `BASE=… node shots.mjs` |
| Паспорт проекта по типовой форме | шаблон организаторов | `python3 passport.py` |
| Ссылка и инструкция запуска | — | `python3 launch_doc.py` |
| Приложения PDF, A4: глоссарий, индикаторы, набор данных, архитектура, тестирование, текст ролика | `appendix.html`, `../Code/docs/dataset.md`, `film/subs.srt` | `node appendix.mjs` |
| Ролик с анимацией и музыкой, 2:33, 1920 × 1080 | `film/` | см. ниже |

| Итоговый архив для СДО: все материалы + PDF-копии документов Word | собранные файлы выше | `python3 package.py [папка]` |

Для node-скриптов нужен Playwright и установленный Chrome (`PLAYWRIGHT=/путь/к/playwright/index.mjs`),
для Python — `python-docx` и `python-pptx`. Поля, которые знает только команда (вуз, ФИО, контакты),
в паспорте и на слайдах стоят в квадратных скобках.

## Ролик

Ролик собирается из `film/film.html`: каждый кадр — функция времени. Такты заданы в `film/timeline.json`, по ним же строится музыка.
Все сцены стоят на одной сетке: поля 80 px, строка подписи 1760 × 120, тело 1760 × 760. Сервис показан
чёткими снимками страниц (окно 1280 px, плотность 2×), камера перемещается по ним. Ввод текста показан снимком на каждый шаг.

1. Кадры сервиса с чистой установки по README (данные `demo_data`):
   `BASE=… DEMO_USER=head PASS=… node film/capture.mjs` → `film/shots/` и `film/shots/boxes.json`.
2. Музыка (синтез кодом, без чужих записей): `python3 film/music.py`.
3. Контур участка для сцены «Геометрия»: `python3 film/shape.py`.
4. Рендер и сведение: `node film/render.mjs` → `video/kod-prozrachnosti-film.mp4`;
   отдельные кадры для проверки: `node film/render.mjs --stills 5,48,103`.
