# Система интерфейса

Источник — файл Figma команды «макеты код прозрачности» (Тимофей). Снимки экранов и листа
«Система интерфейса • Обзор» лежат в `../design/figma/` (папка проекта рядом с `Code`).

Сервис устроен как рабочее приложение: шапка с разделами, карточки на светлом фоне,
поиск внизу экрана. Лендинга нет.

Шапка (кадр «главная»): логотип `static/brand/zeus.svg` (выгружен из Figma) слева, разделы
по центру, справа имя и аватар — по нажатию меню с ролью и «Выйти».

Вход (кадр «вход»): `templates/registration/login.html`, карточка формы собрана на shadcn/ui
(`frontend/`, сборка кладёт `static/auth/`), слева картинка `static/brand/login.webp` из Figma.
Демонстрационная запись `12345` / `12345` (роль «Руководитель», имя «Алексей М.») создаётся
командой `demo_users`, когда включено `ENABLE_SYNTHETIC_LOGIN` (локально всегда, на стенде —
переменной окружения `ENABLE_SYNTHETIC_LOGIN=1`).

Окно «Загрузить документ» (кадры «док», «док2»): одно на все страницы
(`dashboard/_upload_documents.html`, `static/js/document-upload.js`, приём —
`dashboard/documents.py`). Открывается кнопкой в реестре объектов, в карточке объекта (документы
привязываются к объекту) и подсказкой «Загрузить документ» в поиске. До 10 файлов за раз (PDF,
DOCX, XLSX, JPG, PNG, TIFF, каждый до 5 МБ), у каждого тип, источник и описание. Документы без
объекта перечислены под реестром; все документы есть в поиске и в истории изменений.

## Разделы

| Раздел в шапке | Страницы | Шаблоны |
|---|---|---|
| Главная | сводка по всем объектам и рекомендации | `dashboard/overview.html` |
| Объекты | реестр (вкладки риска и решений) и карта, переключатель «Список · Карта»; карточка объекта со сводкой и графом | `dashboard/case_list.html`, `dashboard/map.html`, `dashboard/case_detail.html` |
| Аналитика | индикаторы, должностные лица, источники, методика (инструкция по этапам) | `dashboard/analytics.html`, `officials.html`, `sources.html`, `methodology.html` |
| История изменений | лента событий: решения, загрузки таблиц и документов, анализы; загрузка таблиц | `dashboard/history.html`, `imports/*.html` |
| Поиск по данным | палитра поиска (строка внизу экрана, «/» или Cmd+K) | `base.html`, `static/js/app.js` |
| Колокольчик | последние события | `base.html` |

Одна лента событий на всё: `cases.selectors.recent_events()`. Счётчики очереди:
`cases.selectors.queue_counts()`.

## Риск и решения

- Вес индикатора — `cases.indicators.Indicator.risk` из таблицы «Индикаторы и источники данных
  Р1 и Р2»: И4 и И10 высокий; И1, И2, И6, И8 средний; И3 низкий.
- Риск объекта — наибольший вес среди сработавших индикаторов (`analysis.services.summarize`).
  Ничего не сработало, но данных не хватило — «Нет данных».
- Решение сотрудника: «Подтверждено», «Не подтверждено», «Нужны сведения». Подтверждённые
  и неподтверждённые объекты уходят из вкладок риска во вкладки решений.
- Вкладки реестра: Все · Высокий · Средний · Низкий · Нет данных · Подтверждено · Не подтверждено.
- Цвета: высокий `--high` (красный), средний `--medium` (оранжевый), низкий `--low` (зелёный),
  нет данных — светлый круг с контуром.

## Токены (одно место — `static/css/app.css`)

- Фон `--canvas` #EFF3F7, карточка `--card` #FFF, элемент управления `--control` #F1F4F4,
  навигация `--nav` #DAE2EA, текст `--text` #222B33, вторичный `--text-2`.
- Экран 1920 × 1080: внешние поля 20, между карточками 16, колонки 564 / 564 / 720 (`.g-main`).
- Карточка: поле 16, радиус 20, без обводки (`.card`). Внутренние скругления 12 (`--r-in`).
- Шрифты: Onest; Geist Mono — заголовки графиков 12 и период 10 (`.t-mono`, `.t-period`).
  Размеры: KPI 48, значение 32, заголовок 24, навигация 20, текст 16, метка 12.
- Готовые детали: `.card`, `.card-head`, `.kpi`, `.prio`/`.prio-item`, `.risk` (точка и слова),
  `.code` (индикатор), `.btn`, `.btn-ghost`, `.pill`, `.pill-line`, `.switch`, `.tabs`, `.input`,
  `.field`, `.rows`/`.row-item`, `.tbl`, `.legend`, `.scale`, `.chart` (`static/js/charts.js`:
  funnel, polar, bars).

## Правила

- Крупные поверхности без обводки; линии только у полей ввода и разделителей списков.
- Статус — цветная точка и слова, без плашек, которые переносятся.
- Строка таблицы открывает запись целиком (`.row-link`), стрелка тихая.
- Текст по левому краю; абзацы длиннее строки — по ширине на широких экранах (`.prose`, `p.j`).
- Тексты без нейросетевых оборотов: см. `docs/text-style.md`.
- Проверка: 1920, 1440 и 375 пикселей; на телефоне всё в одну колонку, без горизонтальной прокрутки.
