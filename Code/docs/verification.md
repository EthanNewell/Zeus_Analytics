# Проверка каркаса

Дата: 14 ноября 2026 года. Локальная среда: Python 3.12, Django 5.2.19, временная SQLite для тестов и отдельная SQLite для браузерного прогона.

| Проверка | Фактический результат |
|---|---|
| Ruff: линтер и формат | Пройдены |
| `manage.py check` | Ошибок нет |
| `makemigrations --check --dry-run` | Изменений не требуется |
| Миграции на пустой локальной БД | Все применены |
| Тесты приложения и настроек | 26 тестов, все прошли с SQLite |
| `collectstatic` | Успешно, статика подготовлена |
| `check --deploy --fail-level WARNING` с настройками стенда | Пройден; два явных исключения HSTS для поддоменов/preload документированы в deploy.md |
| Gunicorn | Запущен на localhost; страницы и статика доступны |
| Браузер: вход → реестр → карточка → результат проверки | Пройден; запись отображается в истории с автором и временем |
| YAML Compose и GitHub Actions | Синтаксис разобран; структура проверена локально |
| Docker-сборка, Compose и MySQL 8.4 | Локально не выполнялись: Docker отсутствует, установленная MySQL 5.7 не поддерживается Django 5.2 |
| Удалённый CI и HTTPS-стенд | Не запускались: нет заданных репозитория, сервера, домена и TLS-сертификата |

В workflow настроены тесты с MySQL 8.4, сборка образа и проверка readiness из собранного образа. Их фактический результат должен быть получен первым запуском CI. Разбор YAML не заменяет `docker compose config` и запуск контейнеров.
