# Сценарий показа (3–5 минут)

Перед показом: данные загружены (`load_tables demo_data`, затем `load_tables real_data`), анализ запущен, открыты две вкладки — «Главная» под `head` и вход. Если стенд недоступен, показывайте скриншоты всех экранов.

## 1. Проблема — 20 секунд
Главная: показатели, приоритетные случаи, рекомендации. «Специалист по профилактике коррупции вручную сопоставляет выписки ЕГРН, акты, протоколы комиссий и данные ЕГРЮЛ. Сервис — рабочее место такого специалиста. Он сопоставляет сделки с землёй, смену категории, правки ПЗЗ и связи с должностными лицами, показывает основания для проверки по каждому объекту и хранит ход проверки. Решение принимает сотрудник».

## 2. Данные — 40 секунд
«История изменений» → загрузки: семь таблиц исследования загружены в исходном виде, Excel. Открыть И3: паспорт набора, источники, «реальных ячеек 13 / синтетических 185». «Жёлтая заливка автора сохранена как признак ячейки. На каждом экране отмечено, какие значения реальные и какие синтетические. Если в файле ошибка, ничего не сохраняется. Повторная загрузка не создаёт дублей».

## 3. Объекты и риск — 30 секунд
«Объекты», вкладка «Высокий». «Риск объекта — наибольший вес среди сработавших индикаторов: И4 и И10 высокий, И1, И2, И6, И8 средний, И3 низкий. Вероятность коррупции сервис не считает. У правила три ответа: сработал, не сработал, нет данных. Нет данных — значит, не проверено». Переключатель «Карта»: контуры окрашены цветом риска.

## 4. Главный пример — 90 секунд
Карточка `61:02:0600010:2843` (Аксайский район).
- И6: участок куплен за 75 дней до начала процедуры, в решении участвовал начальник отдела архитектуры, сервис нашёл его ИНН среди прежних учредителей фирмы-покупателя; отметка исследователя совпадает.
- И1: категорию сменили через 271 день после покупки.
- И10: повтор того же лица в 4 эпизодах — исследователь перечислил 5, объекты 4 из 5 есть в таблицах других индикаторов.
- Хронология составлена из событий трёх таблиц.
- «Исходные факты»: каждое поле с ячейкой Excel и происхождением.
- Переключатель «Граф»: индикаторы → комментарии коллег → решение. Нажать «да» с коротким обоснованием → решение «Подтверждено» с автором и временем; объект уходит из вкладки «Высокий» во вкладку «Подтверждено»; факты и результат правил не меняются.

## 5. Геометрия — 30 секунд
Карточка `61:02:0120105:331`: контур с узким выступом к реке. «Сервис считает коэффициент заполнения по координатам: 0,593. Площадь сошлась с таблицей до 0,4 %». Объект на карте: «Объекты» → «Карта».

## 6. Реальные данные — 40 секунд
- Генплан Ростова (реальное постановление № 763) — «нет данных»: границы зоны в приложении к постановлению, которого нет. Сервис перечисляет недостающие данные.
- Реальные земельные торги (13 лотов Ростовской области с torgi.gov.ru, выгрузка 19.11.2026): «Объекты», фильтр по И4. Карточка `61:11:0600007:653` (Заветинский район) — И4 сработал: единственный участник, цена договора равна начальной — 1 733 130 ₽. Всего И4 сработал на 9 лотах из 13; на 4 цена выросла, правило не сработало.
- Углич (реальные торги из набора исследования, продано помещение) — сработал И4: единственный участник, цена договора равна начальной.

## 7. Проверка качества — 30 секунд
«Аналитика» → «Методика» → сверка: 69 из 70 совпали с разметкой исследования (у 13 реальных торгов разметки нет, в сверку они не входят). Расхождение одно: совпала только фамилия, правило требует документ. «Совпадение фамилии связью не считается: так записано в ТЗ».

## 8. Итог — 20 секунд
Автоматизировано: сбор фактов с происхождением, 7 правил с объяснением, риск объекта, хронология, граф истории, карта, история проверки, выгрузка. Остаётся сотруднику: достоверность документов, связь лиц, решение. Следующий шаг — подключить выгрузки ЕГРН/НСПД и приложения к актам.
