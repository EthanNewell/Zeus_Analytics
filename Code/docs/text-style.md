# Как писать тексты сервиса и материалов

Один свод для всего, что читает человек: интерфейс сервиса, тексты правил, презентация, ролик, паспорт,
инструкция, README. Читатель — специалист по профилактике коррупции, проверяющий, член жюри.

## Главное

Текст сообщает факт, действие или условие. Каждое предложение можно проверить по сервису или по данным.
Если предложение нельзя проверить, его нет.

## Нельзя

- **Выдуманные противопоставления.** «не X, а Y», «X, а не Y», «не просто X», «это не X — это Y»,
  «вместо X — Y», «X ≠ Y», когда X никто не утверждал. Пишем только Y.
  Было: «Сигнал, а не обвинение». Стало: «Индикатор — повод для проверки».
- **Метафоры и образы.** «видны по фактам», «факты разбросаны», «сшивает», «складывается в картину»,
  «на ладони», «под лупой», «прозрачность» в переносном смысле, «ключ», «мост», «путь», «сердце»,
  «голос данных», «свет», «тень», «один экран» как образ.
- **Пафос и оценки себя.** «уникальный», «инновационный», «умный», «мощный», «удобный», «бесшовный»,
  «революционный», «впервые», «гениально». Пишем, что сервис делает, — оценку даст читатель.
- **Риторика.** Вопросы к читателю, «Представьте…», «Секрет в том, что…», тройки абстрактных слов
  («быстро, точно, прозрачно»), восклицания, многоточия, драматичное тире ради паузы.
- **Канцелярит.** «осуществляет», «является», «данный», «в рамках», «производится», «функционал»,
  цепочки родительных падежей. Тире ставим в определениях («И6 — связанное лицо до процедуры»),
  не ради эффекта.
- **Англицизмы**, где есть русское слово: «дашборд» → «сводка», «фича» → «возможность».

## Как надо

- Заголовок называет, что в блоке: «Загрузка таблиц», «Почему объект в реестре», «Сверка с разметкой».
- Подпись говорит, что видно и зачем: «Восемь объектов с высоким приоритетом. Строка открывает карточку».
- Числа, даты, коды, кадастровые номера, названия правил и источников не меняются и не округляются.
- Названия и коды индикаторов (И1 «Покупка до смены категории» и другие) взяты из ТЗ — не переименовываем.
- Ограничения говорим прямо: «Данные демонстрационные: часть сведений синтетическая».
- Короткие предложения, действительный залог, глагол в начале действия: «Загрузите таблицу», «Откройте карточку».

## Общие формулировки

Одни и те же мысли во всех материалах звучат одинаково.

| Мысль | Формулировка |
|---|---|
| Что это | Рабочее место специалиста по профилактике коррупции в земельных отношениях |
| Что делает | Сопоставляет сделки с землёй, смену категории, правки ПЗЗ и связи с должностными лицами, показывает основания для проверки по каждому объекту |
| Главная строка | Земельные решения по данным реестров |
| Принцип 1 | Индикатор — повод для проверки |
| Принцип 2 | Нет данных — значит, не проверено |
| Принцип 3 | У каждого значения есть источник |
| Принцип 4 | Решение принимает сотрудник |
| Приоритет | Объекты разложены по пяти уровням приоритета; вероятность коррупции сервис не считает |
