Методика

Каждый индикатор — отдельное правило с версией. Правило берёт только исходные факты и само пересчитывает всё, что в таблице было формулой. Результат — один из четырёх статусов, объяснение и список недостающих сведений.

СработалСочетание обстоятельств найдено — повод для проверки
Не сработалТолько для проверенных правил и имеющихся сведений
Недостаточно данныхНельзя сделать вывод; это не «риска нет»
Не применимПравило не относится к объекту

Итог по объекту

  • Высокий приоритетПодтверждённая связь с должностным лицом (И6), повтор лица (И10) или два основных индикатора сразу
  • Требует проверкиСработал один основной индикатор
  • Контекстный признакТолько И3: показывает механизм выгоды, сам приоритет не поднимает
  • Недостаточно данныхНичего не сработало, но где-то не хватило сведений
  • Сигналов нетНи одно правило не сработало на имеющихся данных
  • Процента «коррупционности» нет намеренно: совпадения не складываются в вероятность вины.
