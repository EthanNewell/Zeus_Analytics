# Zeus Analytics / «Код прозрачности»

Веб-приложение для выявления коррупционных рисков в сфере кадастра: Django 5.2 LTS, Python 3.12, MySQL 8.4.

Работает полный путь: вход по ролям → загрузка таблиц исследования (xlsx/csv) с происхождением каждой ячейки → семь версионированных правил (И1, И2, И3, И4, И6, И8, И10) → реестр с приоритетом → карточка с объяснением, хронологией и исходными фактами → запись проверки сотрудника → CSV. Сверка с разметкой исследования — 69 из 70. 58 тестов проходят на SQLite и MySQL. Подробности — в [Code/README.md](Code/README.md), результаты проверки — в [журнале](Code/docs/verification.md).
