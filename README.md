# Zeus Analytics / «Код прозрачности»

Каркас веб-приложения на Django 5.2 LTS, Python 3.12 и MySQL 8.4.

Реализованы вход и роли, закрытый реестр, карточка, история проверки, защищённая выдача документов и CSV-выгрузка. Подготовлены Docker Compose, HTTPS-прокси и GitHub Actions с MySQL. Импорт и земельные правила имеют точки подключения и пока возвращают HTTP 501 без изменения данных.

Локально прошли 26 тестов с SQLite, проверки Django и Ruff; вход и сохранение истории проверены в браузере. Docker/MySQL 8.4 и удалённый стенд ещё не запускались. Подробности и ограничения указаны в журнале проверки.
