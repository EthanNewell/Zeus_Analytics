# Zeus Analytics / «Код прозрачности»

Рабочее место специалиста по профилактике коррупции в земельных отношениях. Сопоставляет сделки с землёй, смену категории, правки ПЗЗ и связи с должностными лицами, показывает основания для проверки по каждому объекту. Django 5.2 LTS, Python 3.12, MySQL 8.4.

Реализовано: вход по ролям → загрузка таблиц исследования (xlsx/csv) с происхождением каждой ячейки → семь правил с версиями (И1, И2, И3, И4, И6, И8, И10) → реестр с приоритетом → карточка с объяснением, хронологией и исходными фактами → запись проверки сотрудника → CSV. Сверка с разметкой исследования — 69 из 70. 63 теста проходят на SQLite и MySQL. Запуск и состав описаны в [Code/README.md](Code/README.md), результаты проверки — в [журнале](Code/docs/verification.md).
