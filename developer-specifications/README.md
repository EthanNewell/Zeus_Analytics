## Назначение продукта и обязательный объём

Специалист муниципального подразделения по профилактике коррупционных правонарушений получает сведения о земельном случае, видит проверяемое сочетание обстоятельств и его основания, затем фиксирует результат своей проверки. Автоматический результат — повод для проверки. Он не устанавливает нарушение, вину или наличие коррупции.

Обязательный путь: **вход → CSV → проверка и сохранение фактов → анализ → реестр → карточка и основания → запись проверки сотрудника → CSV-выгрузка**. Используем Python, Django, MySQL, Django Templates; небольшой JavaScript допустим. Отдельный SPA, публичный API, OCR/LLM, очередь задач и новые подключения к реестрам в обязательный объём не входят. Карта, граф, PDF и сложная статистика — после завершения основного пути.

Базовый набор правил — Р1.2, Р1.6 и контекст Р1.8. Их применимость подтверждают №2 и №3 по доступным полям 14 ноября. Если данных нет, используются явно обозначенные синтетические примеры или фиксируется «недостаточно данных». Изменение набора принимает №1 с обновлением контрактов и эталонов.

Работа разбивается на задачи по 2–6 часов с одним владельцем и проверяемым результатом. У каждого исполнителя — одна основная задача одновременно. Ветки короткие, PR проходят проверку напарником и CI. Блокер более 30–60 минут сообщается №1. При отставании сначала сокращаются дополнения и сложность сводки; основной путь, объяснения и сохранность истории обязательны.

## Условия общей приёмки

- Сквозной путь повторён на MySQL и стенде; другой разработчик воспроизвёл запуск по README.
- Неверный CSV не оставляет частичных предметных данных; повторный импорт не размножает записи.
- Все четыре статуса правил различимы; приоритет, полнота и происхождение показаны отдельно.
- Контрольный набор содержит минимум 15 сценариев с ожидаемыми результатами; сохранён отчёт прогона.
- История сотрудника сохраняется после повторного анализа; автор и время назначаются сервером.
- Гость и пользователь без разрешения не получают данные, вложения и CSV; запись защищена CSRF.
- Демонстрационные выводы явно обозначены на экранах и в выгрузке.
- Измерены время импорта и анализа, сохранены версия релиза и резерв демонстрации.
